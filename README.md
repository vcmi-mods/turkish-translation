# How to play to Heroes of Might and Magic III in Turkish

1. Buy _Heroes of Might and Magic III Complete Edition_ on GOG (not the HD version)
1. Install the game
1. Download VCMI (free)
1. Install VCMI
1. When installing VCMI, specify the location of the base game's `Data`, `MP3`, and `Maps` folders.
1. Set the language to _Turkish_
1. Install the _Türkçe çeviri_ mod
1. Launch the game

# Heroes of Might and Magic III Türkçe Nasıl Oynanır?

1. GOG'dan _Heroes of Might and Magic III Complete Edition_'ı satın alın (HD sürümü değil)
1. Oyunu yükleyin
1. VCMI'yi indirin (ücretsiz)
1. VCMI'yi yükleyin
1. VCMI'yi yüklerken, ana oyunun `Data`, `MP3` ve `Maps` klasörlerinin konumunu belirtin.
1. Dili _Türkçe_ olarak ayarlayın
1. _Türkçe çeviri_ modunu yükleyin
1. Oyunu başlatın
